FREE TIER SERVICES
================================================================================

--------------------------------------------------------------------------------
DATABASE: Neon PostgreSQL
--------------------------------------------------------------------------------
URL:            https://neon.tech
Free Tier:      0.5 GB storage, 190 compute hours/month
Features:       - Serverless PostgreSQL
                - Branching for dev/staging
                - No pause on inactivity
                - Connection pooling built-in
Capacity:       ~200,000 jobs

Why Chosen:     Best free PostgreSQL, serverless, always-on


--------------------------------------------------------------------------------
SEARCH: PostgreSQL Full-Text Search (Built-in)
--------------------------------------------------------------------------------
Cost:           $0 (included with Neon)
Features:       - Full-text search with ranking
                - Trigram similarity for fuzzy matching
                - GIN indexes for performance
                - JSONB for faceted filtering

Example Setup:
    -- Create search index
    CREATE INDEX jobs_search_idx ON jobs 
    USING GIN (to_tsvector('english', title || ' ' || description));

    -- Search query
    SELECT * FROM jobs 
    WHERE to_tsvector('english', title || ' ' || description) 
          @@ plainto_tsquery('english', 'react developer')
    ORDER BY ts_rank(...) DESC;

Why Chosen:     Free, good enough for 500K+ jobs, no extra service


--------------------------------------------------------------------------------
CACHE & QUEUE: Upstash Redis
--------------------------------------------------------------------------------
URL:            https://upstash.com
Free Tier:      10,000 commands/day, 256 MB storage
Features:       - Serverless Redis
                - REST API (works in edge/serverless)
                - BullMQ compatible
                - Global replication available

Use Cases:      - API response caching
                - Rate limiting
                - Job queue (BullMQ)
                - Session storage

Why Chosen:     Only free serverless Redis, works with BullMQ


--------------------------------------------------------------------------------
OBJECT STORAGE: Cloudflare R2
--------------------------------------------------------------------------------
URL:            https://developers.cloudflare.com/r2
Free Tier:      10 GB storage, 10M Class A ops, 10M Class B ops/month
Features:       - S3-compatible API
                - No egress fees (huge advantage)
                - Global CDN included

Use Cases:      - Raw scraped HTML/JSON backup
                - Company logos
                - Export files

Why Chosen:     Most generous free tier, no egress costs


--------------------------------------------------------------------------------
FRONTEND HOSTING: Vercel
--------------------------------------------------------------------------------
URL:            https://vercel.com
Free Tier:      100 GB bandwidth, unlimited deployments
Features:       - Built for Next.js
                - Automatic HTTPS
                - Preview deployments for PRs
                - Edge functions
                - Analytics (limited free)

Why Chosen:     Best DX for Next.js, generous free tier


--------------------------------------------------------------------------------
BACKEND HOSTING: Railway
--------------------------------------------------------------------------------
URL:            https://railway.app
Free Tier:      $5 credit/month (~500 hours)
Features:       - No sleep on inactivity
                - Easy PostgreSQL/Redis add-ons
                - GitHub integration
                - Automatic deployments

Why Chosen:     No cold starts, always running, easy setup


--------------------------------------------------------------------------------
CRON/SCHEDULER: GitHub Actions
--------------------------------------------------------------------------------
URL:            https://github.com/features/actions
Free Tier:      2,000 minutes/month (public repos unlimited)
Features:       - Cron syntax scheduling
                - Access to secrets
                - Can run any script
                - Matrix builds for parallel scraping

Use Cases:      - Scheduled scraper runs (every 6 hours)
                - Database maintenance jobs
                - Sitemap generation

Example Workflow:
    name: Scrape Jobs
    on:
      schedule:
        - cron: '0 */6 * * *'  # Every 6 hours
    jobs:
      scrape:
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v4
          - run: npm ci
          - run: npm run scrape
            env:
              DATABASE_URL: ${{ secrets.DATABASE_URL }}

Why Chosen:     2000 min/month is plenty, integrated with repo


--------------------------------------------------------------------------------

LOCAL DEVELOPMENT
================================================================================

Docker Compose provides local PostgreSQL and Redis:

    docker-compose up -d        # Start services
    npm run dev                 # Start all apps

Services:
    - PostgreSQL: localhost:5432
    - Redis: localhost:6379
    - Web: localhost:3000
    - API: localhost:3001
