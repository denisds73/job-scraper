TIER 1: ATS PLATFORMS (PRIMARY SOURCES)
================================================================================

1. GREENHOUSE BOARDS API
--------------------------------------------------------------------------------
   Base URL:    https://boards-api.greenhouse.io/v1/boards/{company}
   Auth:        None
   Rate Limit:  ~100 req/min (safe estimate)
   Format:      JSON
   
   Endpoints:
   - GET /jobs                    # List all jobs
   - GET /jobs?content=true       # Jobs with full descriptions
   - GET /jobs/{job_id}           # Single job detail
   - GET /departments             # List departments
   - GET /offices                 # List offices/locations
   
   Example:
   curl "https://boards-api.greenhouse.io/v1/boards/airbnb/jobs?content=true"
   
   Notable Companies: Airbnb, Coinbase, Stripe, Discord, Figma, Notion, 
                      Pinterest, Robinhood, Shopify, Twitch (~8,000+ total)


2. LEVER POSTINGS API
--------------------------------------------------------------------------------
   Base URL:    https://api.lever.co/v0/postings/{company}
   Auth:        None
   Rate Limit:  ~60 req/min (safe estimate)
   Format:      JSON
   
   Endpoints:
   - GET /                        # List all jobs
   - GET /?mode=json&group=team   # Grouped by team
   - GET /{job_id}                # Single job detail
   
   Example:
   curl "https://api.lever.co/v0/postings/netflix"
   
   Notable Companies: Netflix, Atlassian, Cloudflare, Twilio, Databricks, 
                      Reddit (~5,000+ total)


3. ASHBY JOB BOARD API
--------------------------------------------------------------------------------
   Base URL:    https://jobs.ashbyhq.com/api/non-user-graphql
   Auth:        None
   Rate Limit:  ~60 req/min
   Format:      GraphQL (JSON)
   
   GraphQL Query:
   curl 'https://jobs.ashbyhq.com/api/non-user-graphql' \
     -H 'Content-Type: application/json' \
     -d '{
       "operationName": "ApiJobBoardWithTeams",
       "variables": { "organizationHostedJobsPageName": "openai" },
       "query": "query ApiJobBoardWithTeams($organizationHostedJobsPageName: String!) { 
         jobBoard: jobBoardWithTeams(organizationHostedJobsPageName: $organizationHostedJobsPageName) { 
           teams { name jobs { id title locationName employmentType } } 
         } 
       }"
     }'
   
   Alternative (some boards):
   GET https://jobs.ashbyhq.com/{company}/jobs.json
   
   Notable Companies: OpenAI, Anthropic, Vercel, Linear, Ramp, Retool (~1,500+ startups)

COMPANY DISCOVERY - FINDING WHO USES WHAT
================================================================================

To identify which ATS a company uses:

1. Visit the company's careers page
2. Check the URL pattern:
   - boards.greenhouse.io/{company} or jobs.greenhouse.io → Greenhouse
   - jobs.lever.co/{company} → Lever
   - jobs.ashbyhq.com/{company} → Ashby
   - apply.workable.com/{company} → Workable
   - jobs.smartrecruiters.com/{company} → SmartRecruiters
   - {company}.recruitee.com → Recruitee
   - {company}.breezy.hr → BreezyHR
   - {company}.jobs.personio.com → Personio

3. Use browser dev tools to check for API calls
4. Check page source for ATS-specific scripts/styles


================================================================================
RATE LIMITING BEST PRACTICES
================================================================================

1. Respect robots.txt crawl-delay directives
2. Add random delays between requests (1-3 seconds)
3. Use exponential backoff on 429/503 errors
4. Rotate user agents
5. Implement request queuing
6. Cache responses to avoid redundant calls
7. Scrape during off-peak hours when possible
